### 关键结论：本机安装依赖的三条铁律
1. **pnpm 必须用 `--node-linker=hoisted`**。默认 isolated 布局要往 `node_modules` 顶层建 400+ 个符号链接，
   本机会间歇性 `Failed to create symlink ... 拒绝访问 (os error 5)` 而失败；hoisted 扁平布局一次通过。
2. **必须加 `--registry=https://registry.npmmirror.com`**。官方源 `registry.npmjs.org` 上 10MB 级大包
   （antd / echarts / typescript / rxjs）会 `operation timed out` 且反复从头重下。
3. **大文件下载在本环境会被网络层截断**（curl 实测：npmmirror 返回 200 但 `size_download=0`）。
   所以 web 端 antd/echarts 根本下不下来 → 改为**复用旧 npm 版 `node_modules`**（见下）。
4. 另需 `export PRISMA_ENGINES_MIRROR=https://registry.npmmirror.com/-/binary/prisma`，
   否则 `@prisma/engines` postinstall 会卡在下载 36MB 引擎；也可直接从旧 `@prisma/engines` 复制
   `query_engine-windows.dll.node` + `schema-engine-windows.exe` 到 `.pnpm/@prisma+engines@5.22.0/node_modules/@prisma/engines/`。

### 最终采用的方案
- **server**：`pnpm install --node-linker=hoisted --registry=https://registry.npmmirror.com` → exit 0（531 包全部命中缓存，2 分 13 秒）。
- **web**：大包下不动，改为把旧 npm 版 node_modules 改名回用（`web/_nm_old_web` → `web/node_modules`）。
  web/package.json 本轮只多了 `packageManager` 字段、**无依赖变更**，旧依赖完全够用（antd 5.29.3 / echarts 5.6.0 / react 18.3.1 / vite 5.4.21）。
- **vite 首次启动会卡死**在 `Re-optimizing dependencies because lockfile has changed`（CPU 空转 15 分钟无进展）。
  原因：旧 npm 版遗留的 `node_modules/.vite` 缓存与 pnpm 锁文件不匹配。**删掉 `.vite` 后重启，1.5 秒 ready**。
