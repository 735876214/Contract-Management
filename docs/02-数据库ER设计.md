# 02 · 数据库 ER 设计（文字描述）

> 所有表主键为 `id String @id @default(cuid())`；金额类字段 `Decimal @db.Decimal(18,2)`；时间统一 `DateTime`。
> 字典关联字段一律存 **字典项编码字符串**（如 `contract_type = 'PURCHASE'`），由字典服务校验，不使用数据库枚举。

## 一、组织与权限域

```
Dept(部门) 1 ──< User(用户)
User >──< Role(角色)            [UserRole 多对多]
Role >──< Permission(权限)      [RolePermission 多对多]
User 1 ──< OperationLog / LoginLog
```

- `dept`：id, name, parentId(自关联), leader, sort, status
- `user`：id, username(唯一), password(bcrypt), realName, phone, email, deptId, status, lastLoginAt
- `role`：id, code(唯一), name, remark, status
- `permission`：id, code(唯一, 如 `contract:create`), name, module
- `user_role` / `role_permission`：关联表

## 二、项目域

```
Project 1 ──< ProjectMember >── User
Project 1 ──< Contract / DailyReport / ContractItem / Settlement / SettlementLedger
Project 1 ──< PaymentPlan / PaymentApply / PaymentRecord / Invoice / InvoiceApply
Project 1 ──< RepaymentAgreement / Notification / ApprovalInstance
```

- `project`：id, code(唯一), name, status(dict: project_status), description, startDate, endDate, managerId
- `project_member`：id, projectId, userId, roleCode(dict: project_member_role：项目管理员/项目成员/只读用户)，`@@unique([projectId, userId])`

## 三、供应商域（独立表，不冗余进合同）

```
Supplier 1 ──< Contract(supplierId)
Supplier 1 ──< DailyReport / ContractItem / RepaymentAgreement(可选)
```

- `supplier`：id, **name 唯一**, legalPerson, legalPhone, contractAuthPerson, contractAuthPhone, contractAuthIdNo, contactName, contactPhone, contactEmail, bankName, bankAccount, address, remark, status(启用/停用), projectId(可空，全局共享时为空)

## 四、合同域

```
Contract >── Supplier(supplierId)
Contract 1 ── 1  ContractExt         (扩展信息：财务一体化编号/采购来源/是否厂家直采/招标名称/付款比例/分供方类别/招标·定标·交底时间/投诉情况)
Contract 1 ──< ContractAttachment    (附件)
Contract 1 ──< ContractChangeLog     (变更前后留痕)
Contract 1 ──< ContractItem          (合同清单)
Contract 1 ──< DailyReport           (日报)
Contract 1 ──< Settlement 1 ──< PaymentApply
Contract 1 ──< PaymentPlan / PaymentRecord
Contract 1 ──< Invoice / InvoiceApply
Contract 1 ──< RepaymentAgreement(可选 contractId)
Contract 1 ──< ApprovalInstance(bizId)
```

- `contract`：id, projectId, **code(编号)**, name, typeCode, supplierId, signDate, amount, taxRate, paymentMethodCode, isFramework, isSupplement, supplementTypeCode, execStatus, approvalStatus, remark, createdBy
  - 唯一约束 `@@unique([projectId, code])`；全局唯一由服务层按系统参数 `contract.code.unique.scope` 校验
- `contract_ext`：contractId(唯一), financeCode, procurementSource, isDirectPurchase, bidName, currentPayRatio, supplierCategory, bidStartDate, bidWinDate, disclosureDate, complaint
- `contract_attachment`：contractId, fileName, url, size
- `contract_change_log`：contractId, field, beforeValue, afterValue, operatorId, createdAt

## 五、模板域

```
ContractTemplate >── DictItem(contract_template_category)
ContractTemplate 1 ──< TemplateVariable     (变量定义)
ContractTemplate 自关联 version/parentId    (版本链与回滚)
Clause(条款库) 独立表
```

- `contract_template`：id, name, categoryCode, tags, status, version, content(HTML), projectId(可空=全局), parentId(上一版本), createdBy
- `template_variable`：templateId, varKey, varLabel, sourceType(SUPPLIER/CONTRACT/MANUAL), defaultValue
- `clause`：id, title, content, categoryCode, status

## 六、日报域

- `daily_report`：id, projectId, periodYear, periodMonth, entryDate, contractId, isAsset, assetSupervision, department, personnel, assetStatus, sourceCode, materialCategory, materialType, materialName, steelBrand, steelCount, spec, unit, weighQty, deductQty, settleQty, isWeighed, noAcceptReason, priceBeforeTax, taxRate, priceAfterTax, amountBeforeTax, amountAfterTax, supplierId, receiveUnit, receiver, laborContract, usePosition, isProxy, plateNo, receiptNo, remark, subcontractPeriod, incomePrice, incomeAmount, stdPrice, stdAmount
- 关联：`projectId → Project`、`contractId → Contract`、`supplierId → Supplier`；`materialType` 字典项通过 `extField1` 指向 `materialCategory` 编码实现联动。

## 七、结算付款域

```
Contract 1 ──< Settlement            (结算单)
Contract 1 ──< SettlementLedger      (结算台账行)
Contract 1 ──< PaymentPlan           (付款计划)
Contract 1 ──< PaymentApply >── Settlement / Invoice   (付款申请，三单匹配)
Contract 1 ──< PaymentRecord         (付款执行/付款台账)
```

- `settlement`：code, typeCode(预付款/进度款/尾款/质保金), amount, deductAmount, actualAmount, settleDate, statusCode, remark
- `settlement_ledger`：contractId, settleMonth, monthSettleAmount, monthInvoiceAmount, settleCount, yearSettleAmount, cumPurchaseAmount, startSettleAmount, monthActualPurchase, factoringDiscount, overdueInterest, yearSettleIncome, cumSettleIncome, isOnAccount
- `payment_plan`：period, planAmount, planDate, condition, statusCode
- `payment_apply`：code, settlementId, invoiceId, applyAmount, payee, bankName, bankAccount, payDate, methodCode, statusCode, remark
- `payment_record`：payMonth, amount, methodCode, receiptUrl, statusCode, remark（同时承载付款台账）

## 八、发票域

- `invoice`：id, projectId, contractId, goodsCategory, settlePeriod, invoiceCode, invoiceNo, typeCode, invoiceDate, issuer, receiver, amountBeforeTax, taxRate, amountWithTax, receiveDate, reviewStatus, responsiblePerson, financeTransferStatus, imageUrl, statusCode, remark
  - 查重：`@@unique([projectId, invoiceNo])`
- `invoice_apply`：projectId, contractId, typeCode, amount, taxRate, buyerInfo, statusCode, remark

## 九、合同清单

- `contract_item`：projectId, contractId, supplierId, materialCategory, materialName, spec, unit, qty, costPrice, taxRate, comprehensivePrice, remark

## 十、还款协议

```
RepaymentAgreement 1 ──< RepaymentDetail    (至少一条)
RepaymentAgreement >── Supplier / Contract(可选)
```

- `repayment_agreement`：projectId, code, supplierId, contractId?, material, signDate, settleAmount, agreedDebtAmount, paidBeforeSign, paidAfterSign, overdueUnpaid, remark（唯一：`@@unique([projectId, code])`）
- `repayment_detail`：agreementId, period, amount, dueDate, remark

## 十一、审批与通知

```
ApprovalFlow 1 ──< ApprovalNode
ApprovalFlow 1 ──< ApprovalInstance 1 ──< ApprovalRecord
                     (bizType + bizId 关联业务单据)
Notification >── User(接收人)
```

- `approval_flow`：code, name, bizType, status, config(JSON)
- `approval_node`：flowId, nodeName, nodeType(会签/或签), approverIds, order, condition
- `approval_instance`：flowId, bizType, bizId, projectId, applicantId, status, currentNode, submittedAt, finishedAt
- `approval_record`：instanceId, nodeName, approverId, action(提交/通过/驳回/转办), comment, createdAt
- `notification`：userId, title, content, type, bizType, bizId, projectId, isRead

## 十二、字典与系统参数

```
DictType 1 ──< DictItem
SysParam(key 唯一)
```

- `dict_type`：code(唯一), name, remark, sort, status, isSystem, scope(GLOBAL/PROJECT)
- `dict_item`：typeCode, itemCode, itemName, sortOrder, status(1启用/0停用), color, remark, extField1（用于 material_type → material_category 联动等）, `@@unique([typeCode, itemCode])`
- `sys_param`：key(唯一), value, remark（如 `contract.code.unique.scope`、`supplier.share.scope`、`multi.project.enabled`、`repayment.code.prefix`）

## 十三、日志

- `operation_log`：userId, module, action, method, url, params, ip, createdAt
- `login_log`：userId, username, ip, userAgent, result, createdAt

## 十四、合同台账（不建表）

`ContractLedger` 为**服务层聚合视图**：以 Contract 为主表，批量 join Supplier、ContractExt，聚合 SettlementLedger / Invoice / PaymentRecord / DailyReport 的汇总值，再计算合规性问题与各项占比。
