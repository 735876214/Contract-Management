# 使用说明（User Guide）

> 面向系统使用者。按菜单自上而下说明「每个功能用来做什么、怎么操作」。
> 想了解系统全貌见 [project-overview.md](project-overview.md)。

## 1. 登录与基本操作

- 打开系统地址（默认 `http://<主机>:9080`），输入账号密码登录。默认管理员 `admin / admin123`，
  **首次登录请立即在右上角用户菜单 → 修改密码**。
- **切换项目**：顶栏左侧下拉选择项目。系统内所有单据都属于某个项目，切换后页面数据整体切换。
- **消息**：顶栏铃铛显示未读数，点击进入消息中心。
- **个人菜单**：右上角头像 → 查看用户名 / 退出登录。
- **折叠菜单**：侧边栏底部按钮；侧边栏顶部搜索框可快速定位菜单。

> 看不到某个菜单 = 当前账号无对应权限，请联系管理员分配角色。

## 2. 工作台与统计报表

- **工作台**：合同数量/总额、累计结算、累计付款等指标卡；近 12 月结算与付款趋势图、合同类型分布；
  待查验发票列表；以及「草稿超 2 小时未完成」的逾期提醒（每 5 分钟刷新）。
- **统计报表**：4 个统计卡 + 4 个图表（收付款趋势、合同类型、发票类型/状态），均按当前项目过滤。

## 3. 采购管理（本项目主流程）

采购以「任务」为单位推进，**必须按阶段顺序完成**，前一阶段未完成后续阶段锁定。

### 3.1 三种采购类型与阶段

| 类型 | 适用 | 阶段链 |
|---|---|---|
| **单项采购** | 常规一次性采购 | 总清单 →（预计≥100 万需**采前会**）→ 采购公告 → 采购文件 → 成交报告 → 价格对比表 → 生成合同 |
| **框架协议采购** | 框架协议下的采购 | 总清单 → 价格对比表 → 框架协议事前说明 → 生成合同 |
| **紧急采购** | 紧急情况 | 总清单 → 生成合同 |

### 3.2 逐步操作

1. **采购发起**：选择采购品类（物资/租赁）、采购类型，填写采购内容、用途，按需勾选是否需采前会；
   编制**总采购清单**（物资名称/规格从物资基础库选择，金额自动计算）→ 提交后生成采购任务。
2. **采前会会议纪要**（仅单项采购且预计金额 ≥100 万）：填写会议信息、采购清单、成本分析表、询价单。
3. **采购公告**（仅单项采购）：采购清单自动取自总清单（只读），补充公告信息。
4. **采购文件**（入口条件：采购公告已完成）：编辑文件内容，可导出/预览合同模板。
5. **成交报告**（入口条件：采购文件已完成）：录入响应单位情况、第一/二轮报价、拟推荐成交候选人。
   支持导入「响应单位情况汇总表」。**退回重发**：若填写有误可在下游合同未签章前退回，回到本阶段重填。
6. **采购价格对比表**（入口条件：成交报告已完成）：选择计价方式（固定/浮动），填写采购效益分析。
7. **框架协议事前说明**（仅框架协议采购）：询价情况、价格对比表、成本分析表，可从价格对比表导入。
8. **生成合同**：阶段全部完成后，系统按采购类型**自动推导合同类型**并推送**草稿合同**到「合同管理 → 合同起草」。

> 各阶段均支持「预览 / 导出 Word / 确认发布」。发布前请先预览，确认变量已正确替换
> （未替换的占位符会以黄色高亮显示）。

### 3.3 采购模板

「基础信息管理 → 采购模板」：为每类模块（公告/文件/成交报告…）维护 Word 模板，
支持变量占位符。采购各阶段的预览与导出**优先套用模板**，无模板时用内置格式。

## 4. 合同管理

### 4.1 合同起草

- 起草页分两个 Tab：
  - **Tab1 物料编码清单（物料池）**：从物资基础库勾选物料加入本合同专属池（可手动新增物料）。
  - **Tab2 合同清单**：从物料池派生条目，填写暂定数量、税前单价、税率（只读，绑定合同税率）、备注；
    含税单价与含税合价自动计算。
- 草稿超过 2 小时未完成会在工作台提醒。
- 可**签章**、按状态**驳回回起草**（审批中/已签章可驳回）。

### 4.2 合同查询

查看已发布/正式合同，支持导出 Word、查看签章状态（已签章=绿色）。

### 4.3 合同台账

**36 列固定顺序**的综合视图：合同基础信息 + 开累结算/审定结算/开累进项税/开累发票/开累付款、
应付款、应付未付、100% 欠款、两个占比、审减额、按年汇总等，均由系统自动汇总。
- 供应商信息实时关联，供应商变更后台账自动更新。
- **合规性问题自动计算**：未签合同先进场、招标/定标/签订时间倒挂、时间数据不完整等。
- 支持**列显隐配置**（保存后下次沿用）与按当前配置导出 Excel。

### 4.4 合同物资清单

按合同/供应商/物资/合同编号组合筛选查看清单；单合同视图支持上移/下移/编辑/删除。

### 4.5 模板与条款

- **合同模板**：富文本编辑 + 变量占位符；按「是否框架 → 是否补充 → 分类 → 模板」生成向导取用；
  支持版本管理与回滚。
- **合同条款**：维护技术/质量/付款/验收等条款，供模板与合同引用。

## 5. 日报与收领

- **总日报**：35+ 字段，列顺序固定；物资种类按材料类别联动；来源物资基础库的字段只读。
- **收领单**：供应单位支持供应商/其他项目/分包商/本项目多类型；领用单位多种；
  综合单价与总价实时计算；可**推送总日报**。
- **资产台账**：登记在用/闲置/报废/丢失数量，调入费与维保费只填金额。

## 6. 结算及付款

- **结算单**：按合同创建，含预付款/进度款/尾款/质保金等类型、扣款、实付金额。
  已提交后可**驳回**回填（草稿不可重复驳回）。
- **结算台账**：按月登记结算/发票/进货等，供台账与报表取数。
- **资金费用台账**：保理费用、逾期利息（按 DAYS360 计息，支持一键生成）；合同资金参数设置。
- **付款管理**：付款记录登记、导入导出，可按项目导出。

## 7. 发票管理

- **收票登记 / 发票台账**：登记进项发票，含票号、金额、税额、税率、责任等；
  可按**二维码批量识别**快速录入；同一项目内**票号唯一**（保存与查询均查重）。
- **开票申请**：发起并审批销项开票。
- **查验**：为预留能力，当前以二维码识别为主。

## 8. 还款协议

主表 + 至少一条还款明细；可关联合同/供应商；协议编号在项目内唯一。支持导出。

## 9. 基础信息管理

| 功能 | 说明 |
|---|---|
| 项目管理 | 项目基本信息（含项目所在省市/工程地点/项目地址/物资产地等）、成员与项目内角色 |
| 供应商库 | 独立主数据，名称唯一；合同中自动带出且**只读**；被引用只可停用 |
| 分包商库 | 分包材料员授权委托书：可预览/导出，签章件上传后状态变「已完成」 |
| 物资基础库 | 一二级分类联动，计量单位取自字典且创建后不可改 |
| 合同模板 / 采购模板 / 合同条款 | 见 §4.5 / §3.3 |

## 10. 系统管理（需管理员）

- **用户**：增删改、分配角色、重置密码。
- **角色**：维护角色并勾选权限（权限按模块树组织）。
- **系统参数**：编号唯一性策略（全局/项目内）、供应商共享范围、台账列配置等。
- **字典**：字典类型 + 字典项（**全系统下拉与标签颜色的唯一来源**）。
  被业务引用的字典项**不可删除、只能停用**；停用后新数据不可选，历史数据正常展示。
- **日志**：操作日志（含变更前后快照）、登录日志。

## 11. 通用能力

- **导入导出**：主要列表支持「下载模板 → 填写 → 上传导入」，以及按当前筛选导出 Excel。
  - 导入规则：**全成功或全失败**（任一行校验不通过则整体不写入并给出错误报告，可下载）；
    数据量超过 1000 行自动转为后台任务，页面会显示进度。
  - 单次最多 5000 行。
- **附件上传**：合同、委托书等支持多附件上传。
- **消息中心**：导入完成等系统事件会发送站内通知。

## 12. 常见问题

| 现象 | 处理 |
|---|---|
| 登录后提示「缺少项目上下文」 | 当前账号未加入任何项目，请管理员在项目管理中添加你为成员 |
| 某菜单看不到 | 无对应权限，联系管理员分配 |
| 采购某阶段点不进去/锁定 | 前一阶段未完成，按阶段顺序推进 |
| 采购完成但在合同起草看不到合同 | 草稿合同按「创建人」归属，须用发布该采购任务的账号查看；或联系管理员 |
| 导入失败 | 下载错误报告查看具体行与原因；确认模板列头未被修改 |
| 台账/报表数字与预期不符 | 台账为实时聚合，先确认相关结算/发票/付款已登记并已提交 |
