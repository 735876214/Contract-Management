# 01 · 需求确认摘要

## 1. 目标与范围

面向工程/采购型企业的合同全生命周期管理系统，覆盖「项目 → 供应商 → 合同 → 日报 → 结算付款 → 发票 → 台账 → 还款协议」主链路，并配套模板、审批、通知、看板与系统管理能力。

## 2. 模块清单（15 个）

| # | 模块 | 关键能力 |
|---|------|----------|
| 1 | 字典管理 | 字典类型 + 字典项，全系统下拉唯一数据源；缓存；引用校验；导入导出 |
| 2 | 多项目管理 | 项目 CRUD、成员与项目内角色、全局项目切换、按项目数据隔离、按部门+角色的数据权限 |
| 3 | 供应商库 | 独立模块（名称唯一）；合同创建自动带出且只读；台账实时关联；被引用只可停用 |
| 4 | 合同管理 | 基础信息 + 执行情况 + 审批状态；新增/编辑/删除（仅草稿）/提交审批/审批/变更留痕/导入导出 |
| 5 | 合同模板管理 | 模板库、分类（字典）、富文本编辑 + 变量占位符、生成向导（框架→补充→分类→模板）、版本与回滚、条款库 |
| 6 | 日报管理 | 35+ 字段；物资种类按材料类别联动；不含合规性问题 |
| 7 | 结算及付款管理 | 结算单、结算台账、付款计划、付款申请、付款执行、付款台账、核销、预付款/质保金、逾期提醒 |
| 8 | 发票管理 | 收票登记、开票申请、查重（项目内唯一）、查验接口预留、发票台账、三单匹配 |
| 9 | 合同清单 | 物资类别/材料/规格/单价/税率/综合单价；可由合同明细生成或手工维护；导入导出 |
| 10 | 合同台账 | 36 列固定顺序综合视图；供应商信息实时关联；合规性问题自动计算；可配置列显隐 |
| 11 | 还款协议管理 | 主表 + 一对多还款明细（至少一条）；可关联合同；项目内编号唯一 |
| 12 | 审批流 | 流程定义（节点/审批人/会签或签/委托）、审批实例与记录、审批中心 |
| 13 | 消息通知 | 站内信；邮件/短信/企微/钉钉接口预留 |
| 14 | 统计看板 | 合同金额、收付款趋势、发票统计（ECharts），按项目过滤 |
| 15 | 系统管理 | 用户/角色/权限(RBAC)、部门、字典、系统参数、操作日志、登录日志 |

## 3. 关键业务规则确认

1. **字典驱动**：所有下拉/单选/复选/标签颜色来自字典表；后端枚举校验同样读字典；字典项被引用不可删除只可停用；默认全局共享，可通过系统参数切换为按项目隔离。
2. **供应商单一数据源**：合同不冗余法人/授权人/联系人/银行信息，仅存 `supplierId`；合同表单自动带出并**只读**；台账实时关联，供应商变更后台账自动更新。
3. **项目隔离**：合同、日报、结算、付款、发票、清单、还款协议等均带 `projectId`；供应商库可配置全局共享（默认）或项目隔离。
4. **编号唯一性**：合同编号默认**全局唯一**，可通过系统参数切换为「项目内唯一」；还款协议编号同理（默认项目内唯一）。前端实时查重 + 后端保存校验。
5. **合规性问题**（不落库，服务层计算）：
   - 执行合同（采购执行合同/租赁执行合同）：进场日期 ≥ 签订日期 → 无问题；早于 → 未签合同先进场。
   - 非执行合同：依次比较开始招标时间 → 定标时间 → 签订时间，命中即标记；关键时间缺失 → 时间数据不完整。
6. **合同台账指标**：开累结算/审定结算/开累进项税/开累发票/开累付款、应付款、应付未付、100% 欠款、两个占比、审减额、按年汇总，均由服务层汇总计算（批量查询避免 N+1）。
7. **生成合同向导**：是否框架协议 → 是否补充协议 → 模板分类 → 具体模板，四步筛选。
8. **删除约束**：字典项被引用、供应商被合同引用时禁止删除，仅可停用；停用后新数据不可选，历史数据正常展示。

## 4. 非功能要求

- 统一返回 `{ code, data, message }`；全局异常过滤与参数校验（ValidationPipe whitelist）。
- 操作日志 / 登录日志留痕。
- 数据权限：项目 + 部门隔离。
- 后端字典缓存，变更即刷新；前端字典按需加载并缓存。
- 台账查询批量聚合，避免 N+1。
- 响应式布局（Grid / Table 横向滚动 / 栅格表单）。
